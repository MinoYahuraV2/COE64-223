# Project Description

This project is part of the course COE64-223.
It consists of a series of laboratory exercises (labs) based on problem statements provided by the instructor.

Each lab requires analyzing the given problem, designing an appropriate solution, and implementing it according to the specified requirements. The focus of this project is on developing problem-solving skills and applying programming concepts through hands-on practice.

# Project Scope

Analyze problem statements assigned by the instructor

Design solutions based on the given requirements

Implement solutions for each laboratory exercise

Practice logical thinking and problem-solving skills

# Tools and Technologies

Java – Used as the main programming language for implementing solutions

Visual Studio Code (VS Code) – Used as the development environment and code editor
